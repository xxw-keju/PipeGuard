# Evaluation suites

This directory contains source-controlled evaluation corpora. Runtime outputs, compiler caches, binaries, and `.artifacts` are intentionally excluded. `provenance.json` records corpus identities and digests.

- `suite2/`: selected five-per-cell, 210-case Suite 2 source/spec corpus with adjudication markers and a frozen selection lock.
- `suite3/`: source-controlled upstream Suite 3 corpus.
- `suite4/`: the frozen 376-case mutation corpus used by the source-based PipeGuard black-box pass.

Suite 2 is selected but remains preliminary until the blockers recorded in its manifest are repaired and independently admitted.
