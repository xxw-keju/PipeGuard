# Suite 2 selected 210-case corpus

This directory replaces the retained 15-variant generation archive with the selected five-per-cell corpus: `2 DSL x 3 result classes x 7 primitives x 5 variants = 210`.

`manifest.json` binds every source/spec file to the independently labelled and marker-adjudicated checker ledger. `selection.lock.json` freezes the exact case IDs and helper identities. The source-controlled helper namespace is `suite/frontend_pairs/sources/`.

The corpus is selected but not yet final-admitted. Fourteen rows remain not scored, and the manifest preserves all ordering/witness, frontend-contract, TMA-label-review, and cross-owner blockers. Labels and retained PipeGuard verdicts were not rewritten during publication. Runtime outputs, binaries, sanitizer logs, and compiler caches are excluded.
