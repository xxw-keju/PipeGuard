# Suite 3

Source-controlled real upstream TileLang and Triton kernel corpus copied from `corpus/upstream/suite3` in the `exp-dsl-tilelang2` worktree. `suite.json` defines the one-representative-per-source evaluation denominator: 964 unique kernels selected from 4,230 case specifications. Runtime scan outputs, captured IR, compiler caches, and binaries are excluded. See `../provenance.json` and `FILES.sha256`.
